## 🚀 Key Features

1. **Multimodal Screenshot & Blueprint Ingestion**:
   - Upload gameplay screenshots, base blueprints, or inventory views.
   - **Gemini 2.5 Flash** inspects UI numbers, building tiers, and item qualities to write hyper-authentic veteran scripts.
2. **Viral Gaming Hook Formulas**:
   - *Warning / Mistake Hook* ("99% of Satisfactory players build this wrong...")
   - *Pro Veteran Secret* ("The hidden mechanic the devs never told you...")
   - *Visual Callout* ("Look closely at this inventory stat...")
   - *Curiosity Question & Shocking Metric*.
3. **High-Impact Gaming Voiceover Studio**:
   - Multi-voice Edge-TTS engine with gamer voices (*Guy Hype Gamer, Christopher Deep Lore, Jenny Streamer, Eric Factory Engineer, Aria Sarcastic*).
   - Phonetic respelling dictionary for difficult game jargon (*FICSIT, Eitr, Shroud, ADA, Anubis*).
4. **9:16 Kinetic Video & Subtitle Engine**:
   - Vertical Ken Burns camera movement synced to gameplay highlights.
   - High-contrast yellow/neon gaming subtitles.
   - 1-Click 60 FPS MP4 video render directly to `/outer/Downloads/DFLTikTokGaming/`.

## ⚡ Quick Start

### 1. Installation
```bash
git clone https://github.com/kmilkos/dfl-tiktokgaming.git /opt/dfl-tiktokgaming
cd /opt/dfl-tiktokgaming
sudo bash install.sh
```

### 2. Manual Run
```bash
npm install
npm run build
npm start
```

Access the studio at: `http://localhost:4005`
